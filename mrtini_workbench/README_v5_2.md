# Workbench 5.2 — analysis refinement

Extract the complete archive in the MRTini repository root, replacing the previous workbench files. Restart `python workbench.py`, then hard-refresh the browser. Keep the existing environment and simulator; no production Rust or Triton modifications or additional packages are needed.

- The 3D state-space panel is deliberately hidden; the interactive 2D PDG remains. Its nodes and edges have stronger visual contrast.
- After a native run, a central active water voxel (fat if water is absent), first RF repetition containing ADC, and middle ADC sample are initialized. Opening the RF or magnetization/echo/slice view loads its diagnostics automatically. Selection changes are debounced; previous numerical results are not used after the acquisition changes. Replay remains available. Automatic diagnostics are loaded on demand when the analysis view is visible, not as a blocking acquisition step.
- Magnetization has point and through-plane-average modes, component and time-range controls, and a correctly resized high-DPI canvas. The average is an analytic rectangular slab integral, applying sinc(kz*thickness) to each complex retained state at the selected voxel. It assumes fixed tissue and fields across the slab; it is not an independently integrated Bloch ensemble or a full 3D voxel average. The time trace is at repetition boundaries; straight connections are not continuous intra-RF evolution. The spatial slice diagnostic evaluates 121, 257 (default), 513 or 1025 points across twice the prescribed slice thickness; it warns if sampled spatial Nyquist is below the maximum represented kz. These sample counts affect only the diagnostic, not the production acquisition or finite-voxel signal model.
- Echo analysis presents complex vector contributions, relative shares of the sum of magnitudes, cancellation, projection along the net signal, and selected-readout component magnitudes. The strongest retained states are tabulated, not plotted as a fictitious continuous rank curve. Clicking the readout chooses an ADC sample. These are RF-history classes for the selected voxel and first coil, not unique spin/stimulated echo identities or whole-phantom fractions. Up to 512 samples plus the selected ADC are shown per repetition.
- RF analysis overlays all six retained transition syntheses and grouped Fourier magnitudes when All six is selected. The graph shows all six edge relations by default, with independent colour and isolation controls; F and Z occupy separate coordinate bands, F- is implicit via conjugation. The graph shows a bounded subset of actual retained edges, using end-of-repetition k_z, not every discarded transition.
- Native raw ADC visualization groups acquired samples by RF repetition, with zero padding. It is not a spatial k-space raster. Physical k-space remains the trajectory-aware viewer; Auto continues to choose DCF for off-grid generated acquisitions. Preview gridded k-space is labeled separately.

## Validation
Run `python -m pytest -q mrtini_workbench` from the repo root (optional NUFFT/DICOM packages affect skipped tests). In the development environment 73 tests passed, 2 skipped. Four additional CPU executor fixture cases verified readout history sums against the scalar ADC diagnostic (max absolute error 4.26e-8), analytic slab Mz against quadrature, and unchanged production ADC output. Browser checks used a local API bridge and synthetic/recovered CPU data; automatic initialization, RF all-relation display, sphere resize, echo view and navigation passed without JavaScript errors. These fixtures are not physical FLASH/RARE validation. Native CUDA and actual scanner-specific trajectories are not tested here.
