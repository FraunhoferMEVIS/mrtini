# MRTini Workbench 4.0

Extract into the existing MRTini repository next to `sim_run.py`, replacing the old workbench files, not `src/`. Stop the previous server first. Start with the existing CUDA environment:

```sh
python -m pip install -r mrtini_workbench/requirements.txt
python workbench.py
```

Open http://127.0.0.1:8765 and hard-refresh. No new runtime dependencies or simulator/Rust/Triton source modifications. The native backend expects the v3.1 prepared GPU API. For earlier sequence generation conventions, see README.md; this document supersedes its descriptions of UI, data exports, comparison and cache behavior.

## Workflow

* **Acquisition:** compact editable numeric inspector (type, arrow keys, or scroll while focused), large reconstruction, real physical ADC trajectory with coil/magnitude/phase/order and playback, physical tissue map inspector with species-specific water/fat parameter values. Click a map voxel and choose its species to access its RF coefficients and magnetization replay. The map is built from actual active voxel positions; its cropped extent and orientation are independent of reconstruction. No assumed native reconstruction-to-phantom pixel registration. B0 offset and B1 scaling modify cloned native data before baking; defaults preserve original values. Imported sequence parameters remain read-only except simulation/field settings.
* **Pathways:** exact whole-graph state and edge overview; click to navigate the bounded graph window. Species filters, kind/activity filters, kx/ky/kz/t projection, window-consistent axis ranges, tracing displayed ancestor/descendant connections, state coordinates and nominal amplitudes. Archive full graph explicitly to inspect after another acquisition or server restart. Compact node snapshots are saved automatically. Archive viewer only replays graph structure; tissue probes use latest live acquisition. Structural comparisons use exact coordinate/kind/layer/species keys (multiset), not proof of identical ancestor chains. Full matching disabled over one million combined states. Display limits are never pruning controls.
* **Physics:** completed or draft sequence strip, click RF to read stored Fourier coefficients and their spatial synthesis; view magnitude/phase/real/imaginary. Coefficient heatmap rows are the six RF relations. Synthesis uses retained taps in the executor's positive spatial phase convention, including the chosen voxel's phase. This is not the untruncated raw Bloch solution. Generated ADC samples link to the sequence timeline using exported absolute ADC times. Imported sequences retain the earlier marker/event-average representation; absolute sample links not inferred. Selected-voxel magnetization replay uses the same retained graph and actual coefficient column with indexed torch accumulation, no mutation of the production engine. Shows point magnetization at repetition ends, and complex coil-1 ADC contributions at the middle sample of the selected RF repetition (strongest 30 rows displayed). Point magnetization uses the PDG conventions, including coherence dephasing; not a continuous intra-RF Bloch trajectory. ADC contributions include voxel dephasing/PD/coil weighting. GPU rounding may differ. Original 3 T tissue isocentre probe remains available in Pathways.
* **Experiments:** run history persists on disk. Shared magnitude display limits; signed and relative magnitude differences (mask reference below 1e-6 of its peak); magnitude-image L2 and complex ADC L2 only for matching geometry/trajectory as appropriate, no phase alignment/regridding. Compare graph counts and exact node identity. Restore protocol, delete saved acquisitions, export numerical files. Sweep up to 20 values sequentially, stop after current acquisition. Report measured complex ADC L2 norm and backend time; these are not tissue-specific contrast curves. Invalid timing fails explicitly. B0/B1 field sweeps require native mode. Preview never supplies invented PDGs, RF or magnetization.
* **Presentation:** nonblocking loading ring and fixed execution trace, dark appearance, responsive right rail, collapsible inspector and execution drawer, vector SVG exports for displayed graph subset and sequence window; browser print stylesheet for Save as PDF. SVG exports are basic vector figures, not a guarantee of journal-ready typography.

## Cache and timing

Single-entry CPU phantom cache is preserved. RF reuse requires the same actual sequence definition, phantom file identity/sampling, RF mode and field settings. A change solely to state budget or threshold reuses baked RF and rebuilds the graph; workspace/kernel mode changes can reuse the graph. Changed physical sequence parameters rebuild the RF/graph; no assumption that identical nominal RF labels imply identical baked spans. External recipe adapters use conservative full-protocol keys. Identical prepared execution reuses its instance and optional CUDA Graph. Caching relies on the read-only input behavior of the recovered optimized prepass/executor; validate on the installed version. Native `_reconstruct` remains unchanged; no independent alternate reconstruction algorithm or cached NUFFT plan introduced. Browser submission-to-result time includes polling; backend stages distinguish numerical execution, preparation and diagnostics. Triton cache-hit counts are not instrumented. 

## Disk and provenance

All files stay local in `mrtini_workbench/runs/<id>/`. `result.npz` contains actual complex ADC, coordinates and complex reconstruction; `maps.npz` contains quantitative maps and physical axes; `graph_nodes.npz` is the compact state snapshot; optional `graph_full.npz` retains edges. `summary.json` stores protocol, metadata and timings, including backend total and graph counts. Exported older result files may not include diagnostic serialization time in their embedded timings; summary is authoritative for backend timing. Native phantom identity includes path, size, modification/change time and slice configuration; it is not a cryptographic content hash. Generated data can be large. Keep `/mrtini_workbench/runs/` out of Git. The included local `.gitignore` does so without changing the repository's own ignore rules. Delete saved runs through Experiments when not needed. Older v3 runs without `summary.json` are not automatically imported; their existing NPZs remain untouched.

Two additional checks using the recovered v3.1 prepared CPU executor found selected-voxel ADC contribution sum absolute differences 6.66e-8 and 1.49e-7 versus a receiver-weighted single-voxel reference, with actual RF tap extraction. Browser smoke test used Chromium with an offline bridge to the real FastAPI test client (localhost navigation was blocked).
