# Workbench 5.1: corrections to v5

Extract into repository root; restart `python workbench.py`, hard-refresh.

- Auto uses Cartesian FFT on-grid; generated off-grid data use iterative NUFFT density compensation. Explicit unweighted NUFFT remains available. Imported data with unverified FOV retain legacy default. Install `torchkbnufft` for non-Cartesian. Weights are saved in `result.npz` and metadata, and the operator is named in UI. Density compensation is not inverse reconstruction and is not a correction for bad trajectory, RF/gradient modelling, off-resonance, or undersampling.
- Measured reference in acquisition viewport; inline DICOM controls, independent window and geometry. No registration or quantitative subtraction. pydicom required for decoding.
- Reconstruction lab inline; operates on saved ADC, shows derived output independently, does not silently replace original archived result.
- Analyze has an actual secondary navigation: RF response, magnetization, slice evolution, echo contributions, pathways, sequence. Encoding links to acquisition. RF view shows available finite waveform, retained RF response, selected transition taps, bounded actual PDG edges. Imported data without waveforms are explicitly labelled. This is not the original raw Bloch bake.
- 3D PDG layer selector defaults to last nonempty visible layer, or preserves user's selected layer; all visible layers mode available. Coordinates from actual graph; global scaling within visible window; overlapping points are possible. No change to simulation pruning.
- Dedicated interactive Bloch sphere for sampled boundary magnetization; cursor is linked to sequence window using first RF-centre time origin. No interpolation presented as continuous intra-RF dynamics.
- Echo mechanism attribution: selected voxel / species, RF layer and ADC sample; separate real-linear propagation of six RF-history classes through merged states, including complex conjugation and longitudinal recovery. Classes indicate mechanisms (direct, single conjugation, multiple conjugation, stored and recalled), not unique primary or stimulated echo identities. A near-zero coherence-time subset (±0.01 ms) is also reported, not a proof of spatial or temporal echo identity. Summed complex residual is reported. Individual merged states' top 30 contributions returned by API. Not a whole-phantom pathway decomposition. Does not alter production simulator.

Tests: `cd mrtini_workbench; python -m pytest -q` (72 passed, 2 skipped here). Added tests for history classification/linearity and DCF dispatch (mocked adapter). Recovered native CPU executor fixture tested on packed and unpacked graphs, max absolute complex decomposition residual 2.15e-7 for tested contributing voxels. Browser smoke tests via offline API bridge; 3D and magnetization fixture events are synthetic browser-test data. CUDA, actual torchkbnufft, DICOM decode, and native BrainWeb visual integration remain unverified here. Original untruncated Bloch response, unique full RF histories, measured registration, and the rest of hardware instrumentation remain outstanding.
