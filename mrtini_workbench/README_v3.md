# MRTini Workbench 3 · Acquisition, Pathways, Sequence

Extract the archive into the repository root beside `sim_run.py`, replacing the previous workbench files. It includes the v2 parameterized native sequence builders and phantom cache fix. No changes to `src/mrtini`, the Rust prepass, or simulator kernels are required. Requires the existing MRTini v3.1 dynamic GPU engine (or a compatible version with `PreparedGPUExecution` and `PackedGraph`). Run `python -m pip install -r mrtini_workbench/requirements.txt` if needed, then `python workbench.py` and open http://127.0.0.1:8765.

## Use
- Acquisition: protocol inspector stays available in all three views. Run on edits (debounced) or click Run acquisition. The status explicitly distinguishes pending edits from a completed result. Pin a reference to show a second image. Export the original complex reconstruction and ADC signal with NPZ export. Backend performance is measured by the existing workbench, not fabricated.
- Pathways: native mode only. Union / Water / Fat modes use real native `case_species`, `node_mask`, and `edge_mask`; case bits are decoded using physical species labels, including a fat-only graph where bit zero is fat. Water and fat views include shared nodes and edges; exact-only membership filters show only the chosen membership. Use the layer window and state-type filters to navigate. The horizontal coordinate is RF layer, and the vertical coordinate is the prepass end-of-repetition k_z in cycles/m. F+ and Z bands have independent vertical scales. Other spatial/time coordinates are retained in the selected node inspector. Multiple states can overlap in the plotted projection: click repeatedly to cycle. Selected incoming/outgoing displayed edges are highlighted. Counts are exact for the full graph; display caps (per-layer state count and 4,500 edges) affect only rendering, not computation. Colors follow the recovered thesis style: water #007C83, fat #B75B0A, shared #7951A2. Node and edge membership are distinct; two shared nodes can have a species-only RF edge. The plot is a graph projection, not a textbook integer EPG or a continuous trajectory between states.
- Isocentre probe: choose GM, WM, CSF or fat, then compute. Uses the **same retained packed graph**, same pulse supports and existing RF bank columns. The probe uses historical 3 T BrainWeb tissue constants, a unit receiver coil, original finite voxel geometry, origin position, and RF/B0/B1 values inherited from a representative contributing native voxel of the chosen species. It is not an independent converged pure-tissue graph; original pruning and emission masks still apply. It is not a point-spin result, and B0/B1 are not forced to ideal values. Actual inherited values and chemical shift (when present) are displayed. The fat probe requires separate baked fat RF banks and fat membership. ADC time is measured from the first RF centre, display is limited to 8192 samples, and no synthetic probe is substituted. Follow acquisition is optional and can add preparation time. Native graph and probe endpoints only access the latest completed native job; there is no second large graph cache or transfer of millions of edges. They reject queries while a new acquisition is running.
- Sequence: generated native sequences expose actual finite RF waveforms (real/imaginary), all three held physical gradients in mT/m, actual ADC times, flip angle and RF phase labels, and a linear time axis. Based on the recovered SMS thesis figure color palette (#193454, #087E85, #C76526, #634D96). Imported presets expose RF centre markers and event-average gradients (not a reconstructed or guessed finite RF waveform); normalized gradients are explicitly labelled normalized/s. The preview timeline is a **design-only** view; preview images are idealized and do not simulate the displayed finite waveforms. Graph and voxel analysis are disabled for preview. Research sequences are not scanner-ready.

## Validation
`cd mrtini_workbench && python -m pytest -q test_native_sequences.py test_phantom_cache.py test_analysis_views.py`
14 tests passed locally (API doubles / graph array fixtures). Also exercised the actual recovered v3.1 prepared Torch CPU executor with synthetic packed graph and GM/WM/fat probe replay; original ADC output was unchanged. Preview FLASH, RARE and EPI API jobs, timeline responses, export, and rejection of synthetic graph/probe requests tested via FastAPI TestClient. Python and JavaScript syntax checks passed. Native Rust/CUDA integration with the installed repository remains unverified here. Browser localhost navigation was blocked by the environment, so visual layout and interaction testing in a real browser remain pending. No claims of GPU speedup are made. The graph and probe operate read-only on the current acquisition; probe uses separate execution buffers. If the installed phantom/artefact classes differ from the recovered v3.1 API, probe errors are surfaced rather than substituting data.
